Exam file format

A complete example:

# Chapter 3 quiz
shuffle: questions, options
show_result: review

1. What is the **area** of this triangle?
![A right triangle with legs 3 and 4](triangle.png)
- 6 *
- 7
- 12
- 14

2. What does this program print?
```
fmt.Println(2 + 3)
```
- `5` *
- `23`
- `2 + 3`
  • The first line is the title: # Title.
  • Optional settings follow the title: shuffle: none | questions | questions, options (default questions), show_result: none | score | review (default score), monitor: on | off (default on; flags leaving the page, copy, paste, right-click and resizing) and duration: <minutes> (a whole number from 5 to 240, default 60).
  • Questions are numbered 1., 2., … at the start of a line.
  • A line ## Title starts a section. The lines after it, up to the next question, are its instructions, shown above the section's first question. Questions keep their running numbers, and the settings go before the first section.
  • Options start with - . Each question needs at least two.
  • Mark exactly one option per question as correct with a trailing *.
  • Text supports bold (**bold**), italics (*italics*), inline `code`, line breaks, fenced code blocks (```) and images (![description](file.png)).
  • To use images, upload a .zip containing the text file and the image files (PNG, JPEG, GIF or WebP).
  • Uploads are limited to 10 MB.
