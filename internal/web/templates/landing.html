Why Answerbox

Less paper, less marking, more teaching.

Made for a real classroom: one teacher, a room of students and the phones they already have.

  1. A

    Marking is done for you

    Every answer is scored the moment a student submits. Fill-in answers understand Indonesian numbers, so 1.003 and 0,5 are read the way your class writes them.

  2. B

    Works on the phones they already have

    Students open a link or type a 6-character code. Nothing to install, and no student accounts to create.

  3. C

    See who is still working

    Results fill in live while the exam runs, so you know who has finished and who has not.

  4. D

    Your data stays on your server

    Answerbox runs on a server you control, with no third-party scripts and no trackers.

How it works

From the first question to the grade book

Before class

  • Write or importType questions in the browser or import a text file. Multiple choice, fill-in and sections.

  • SchedulesSet the times and the exam opens and closes by itself.

During the exam

  • Projector viewShow the code large on the classroom screen.

  • Optional monitorFlags students who leave the page, copy or paste.

Afterwards

  • CSV exportDownload the results for your grade book.

  • Revision historyEvery change to an exam is kept.

// for developers and self-hosters

Small enough to run yourself

One Go program and one SQLite file, packaged as a container image.

stack

  • A single Go binary
  • Server-rendered HTML
  • SQLite: the whole database is one file
  • Tiny same-origin scripts, only for the student pages and a few teacher conveniences

deploy

  • Container image ghcr.io/fiatcode-gh/answerbox, running as non-root
  • Health check at /healthz
  • Configured with environment variables
  • Teachers sign in with Google (OpenID Connect)

privacy & security

  • No third-party scripts or trackers
  • A strict Content-Security-Policy
  • No student accounts: students join with a code and their name

Run the container:

podman run -d -p 8080:8080 \
  --env-file .env \
  -v answerbox-data:/data \
  ghcr.io/fiatcode-gh/answerbox:latest
